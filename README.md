# Game tech exploring
Learning repository focused on exploring modern game development technologies with Flutter and Flame.

## Tech Stack

### Core
- Dart
- Flutter
- Flame Engine

### State Management
- Riverpod

### Local Storage
- Hive

### Audio
- flame_audio

### Animation
- Flame
- Rive

### UI & Theme
- Light Mode
- Dark Mode

### DevOps
- GitHub Actions

## Goals

- Learn Flutter game architecture
- Understand Flame Engine fundamentals
- Explore game state management with Riverpod
- Implement local persistence with Hive
- Integrate audio and animation systems
- Automate testing and deployment using GitHub Actions
- Build reusable game development patterns and best practices
